# President-Wallpaper-Rotator

**IMPORTANT, pictures are from `https://www.whitehousehistory.org/galleries/presidential-portraits`**

This wallpaper rotator sets your wallpaper based on a list of Presidents in order from the index. You can also `Right-Click` on your desktop and press `Personalize`, you can then fit your picture on how you want it and it will save across all pictures.

I take no responsibility if this script does anything potentially bad to your computer. To use it, just click on the .exe or set Windows
`Task Schedular` for it so it does it everyday. To set it up for Windows `Task Schedular`, press the `Windows Key`. Then, you will
search for `Task Schedular`. Click on the one that says `Task Schedular`. Then click `Create Basic Task...`. Follow the prompts and fill out what it tells you. Then, browse to the `.exe` when it asks you and select that for executing that program when it asks you.
