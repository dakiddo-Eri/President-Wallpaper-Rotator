# President-Wallpaper-Rotator

**IMPORTANT, pictures are from `https://www.whitehousehistory.org/galleries/presidential-portraits`**

This wallpaper rotator sets your wallpaper based on a list of Presidents in order from the index. You can set it up for daily rotation with Windows `Task Schedular` which you can search up how to do. You can also `Right-Click` on your desktop and press `Personalize`, you can then fit your picture on how you want it and it will save across all pictures.
